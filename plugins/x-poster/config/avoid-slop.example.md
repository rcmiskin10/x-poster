# Avoid-slop guidelines (OPTIONAL, off by default)

This file is a template. The command does NOT load it unless you set `AVOID_SLOP_PATH` to a file path
(point it here, or at your own copy). It lets you enforce your own anti-patterns without the plugin
shipping anyone else's list.

## Forbidden words / phrases (examples — edit to taste)
- Decorators: "game-changing", "revolutionary", "powerful", "unlock", "supercharge", "level up"
- Hedges: "might be worth considering", "it's important to note that", "in many ways"
- Engagement bait: "Agree?", "What do you think?", "Drop a 🔥", "Most people get this wrong" (without the answer)
- AI-tells: "Let's dive in", "Here's the thing:", "It's not just X, it's Y", em-dash ladders

## Formatting bans
- No em-dashes (— or --). Use periods, colons, or commas.
- No markdown bold/markup in shipped text — X renders it literally.

## Structural
- Cut throat-clearing intros and recap outros.
- Don't list 5 items where 3 do the work.
