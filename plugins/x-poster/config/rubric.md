# Bookmarkability rubric (built-in, generic)

The `/x-poster:x-post` command scores a draft against this 5-item checklist before showing it to
you. It is a quality nudge, not a gate — you always confirm the final text yourself. Ship guidance:
**aim for ≥4 of 5.** This is deliberately minimal; point `VOICE_CONFIG_PATH` at your own file if you
want a stronger voice/quality bar (see README).

Score each 0 or 1:

1. **One concrete claim or number** — says something specific, not a vague generalization.
2. **Hook in the first line** — the opening line earns the next line; no throat-clearing intro.
3. **No slop** — no filler, hedging ("might be worth considering"), or AI-tell phrasing
   ("game-changing", "let's dive in", "it's not just X, it's Y"). No em-dashes in shipped text.
4. **Fits the medium** — each tweet ≤280 chars; a thread reads as one linear argument, not a list of
   disconnected claims.
5. **Worth a save** — teaches something, shows proof, surprises, or is reusable later.

If a draft scores low, revise the idea before polishing the words.
